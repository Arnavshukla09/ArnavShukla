# Arnav Shukla - Portfolio

This repository contains my personal portfolio website, designed to showcase my projects, architecture, and skills as a Full Stack & AI Engineer. 

## Features
- **Agent Loop Metaphor:** A cohesive visual narrative (SENSE → PLAN → DECIDE → ACT) tying the architecture and project framing together.
- **Arcane Hexcore Aesthetic:** A dark-mode first, faceted glassmorphism theme using Three.js for procedural 3D elements without heavy assets.
- **Componentized Vanilla JS/CSS:** Fast, lightweight single-page architecture prioritizing load times and smooth scroll mechanics (Lenis + GSAP).

## Tech Stack
- **Frontend:** HTML5, Vanilla CSS3 (Custom Properties), Vanilla JavaScript
- **3D & Animation:** Three.js, GSAP, ScrollTrigger, Lenis Smooth Scroll

## Projects Showcased
- **Rural Healthcare AI Platform:** Edge-optimized, localized SLMs with RAG functionality for offline healthcare.
- **Eco-Loop:** Autonomous waste-management agent loop powered by PostGIS and MCP.
- **TalentMatch AI:** Low-memory scoring engine using Scikit-learn and Groq API.
- **CampusCart:** Multi-vendor campus marketplace built on Flask and SQLAlchemy.
