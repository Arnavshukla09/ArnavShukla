Eco-Loop — Autonomous Building AI
Honeywell Hackathon 2024 · agentic systems
50% energy reduction 9 MCP tools 100% fault recovery (30 injected failures)

A closed-loop AI agent that runs a commercial building's HVAC in real time — a local Qwen2.5 model reasoning over live sensor data from an EnergyPlus physics simulation, exposed to any MCP client as a set of controllable tools.

  • Locally-hosted Qwen2.5 (via Ollama) makes setpoint decisions every 30 seconds against a physics-accurate thermal simulation
  • Built a FastMCP server exposing 10 sensor/actuator tools — the building becomes a standard MCP-controllable device
  • If the LLM call fails or hallucinates invalid JSON, control silently falls back to a deterministic rule-based controller
  • Live telemetry streamed to a React dashboard over WebSockets — Temperature, Energy, PMV/PPD comfort

TalentMatch AI
ATS scoring engine · hybrid ML + LLM pipeline
<21ms ranking 240MB container ~24.6 req/s

Opens up the resume-screening black box: scores a resume against a job description and explains exactly why, using cheap deterministic math where possible and an LLM only where reasoning is actually needed.

  • TF-IDF + Logistic Regression (scikit-learn) handles fast semantic ranking (model trained on synthetic ATS resume-to-JD matches); Groq LLMs handle parsing and explainability
  • Replaced deep-learning dependencies with scikit-learn to fit inside a 512MB-RAM cloud instance
  • Stateless-by-design pipeline: files are processed in a temp directory and explicitly deleted afterward
  • Fully Dockerized, with a companion Chrome extension for scoring directly from job boards
