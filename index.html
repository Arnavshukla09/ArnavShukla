Rural Healthcare Platform
2024 · Full-stack + AI · telehealth for underserved regions
274ms avg query 6,616 facilities indexed 100% security audit pass

A Next.js telehealth platform built for rural India: AI symptom triage in Hindi and English, PostGIS-powered facility mapping, and Jitsi teleconsultation — secured end to end with PostgreSQL row-level security.

  • Row-Level Security policies guarantee a patient's queries can only ever return their own records, even if the API layer is compromised
  • Gemini-powered triage returns structured, urgency-ranked JSON with a deterministic rule-based fallback
  • PostGIS ST_DWithin queries return the nearest facilities without shipping thousands of rows to the client
  • Upstash Redis rate-limiting on AI endpoints, Playwright E2E coverage on critical flows

2024 · Honeywell Hackathon · agentic systems
50% energy reduction 9 MCP tools 100% fault recovery

A closed-loop AI agent that runs a commercial building's HVAC in real time — a local Qwen2.5 model reasoning over live sensor data from an EnergyPlus physics simulation, exposed to any MCP client as a set of controllable tools.
